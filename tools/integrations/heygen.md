# HeyGen

HeyGen is an AI avatar video platform for script-to-video, avatars, templates,
and asynchronous render status.

## Hosted Agent execution status

`execution_unavailable`: the current Hosted Agent execution contract has no
reviewed HeyGen action, provider connection, asset upload, or asynchronous
start/poll adapter.

Never call HeyGen through shell, install a remote MCP bridge, request an API key,
or return a provider media URL as if it were a project asset. Prepare the script,
avatar/voice requirements, dimensions, language, and review checklist, then ask
the user to run it in HeyGen. A future implementation must use a purpose-built
typed start/poll action and persist the result as a project-scoped asset.

## Planning fields

- script and pronunciation notes;
- avatar and voice choice;
- language/localization;
- 16:9, 9:16, or 1:1 dimensions;
- brand background, captions, and CTA;
- target duration;
- approval owner and publication destination.

## Common marketing uses

| Use case | Planning approach |
|---|---|
| Product explainer | Feature-to-benefit script with a visual beat sheet |
| Feature announcement | Reusable template plus current screen recording |
| Multilingual content | One approved source script, localized variants |
| Personalized outreach | Explicit approved variables; no sensitive data |
| Weekly update | Stable template with a reviewed new script |
